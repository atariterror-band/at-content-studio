# Content Studio records

The web app saves each draft as a JSON file in `drafts/` and each completed item in `completed/`. These files are read directly from the public repository. Saving or deleting requires a GitHub fine-grained token with Contents read and write access to this repository; the token stays in the current browser tab memory and is never stored in the repository.

Both folders are public because this repository is public. Do not store private or sensitive material here.
